# Biz Buddy AI

Build MVP Ai Business Manager: an AI POS Business Manager for Small Medium Business Enterprises.
Workflow must be user-friendly with easy registration and a single P499 monthly per user subscription model.
- Front Hero landing page with a setup tutorial walkthrough and an interactive demo dashboard where users can modify numbers and see real-time charts recalculate without needing to log in.
- App workspace supporting both light and dark themes.
- Responsive design across desktop browsers and mobile devices, formatted as an installable PWA for Android and iOS.
- Visually striking dashboard with graphics, metric cards, revenue charts, category/margin pie charts, and clean information architecture.
- POS checkout register with item scanning, quick payment processing (Cash, E-wallets/QR, Card), and receipt generation.
- AI Business Manager copilot feature providing proactive inventory insights, reorder alerts, dead-stock identification, and conversational store performance queries.
