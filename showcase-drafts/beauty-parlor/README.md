# Ganda Hub — Beauty Parlor dashboard sample

- Preview route: `/showcase/beauty-parlor`
- Theme: Plum and exact #FF00FF accents
- Starting weekly sales: ₱44,000
- Interactive controls: category sales, profit margin, weekly change, and average customer spend
- Live outputs: sales, profit, customer count, goal progress, daily chart, sales mix, and operational alerts
- Languages: English and Tagalog

This folder is the independent review copy for the beauty parlor scenario. The reusable implementation lives in `src/components/ShowcaseDashboard.tsx`; scenario data lives in `src/lib/showcase-scenarios.ts`.
