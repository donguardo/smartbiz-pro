# Lutong Bahay — Restaurant dashboard sample

- Preview route: `/showcase/restaurant`
- Theme: Fiesta red and gold
- Starting weekly sales: ₱155,000
- Interactive controls: category sales, profit margin, weekly change, and average customer spend
- Live outputs: sales, profit, customer count, goal progress, daily chart, sales mix, and operational alerts
- Languages: English and Tagalog

This folder is the independent review copy for the restaurant scenario. The reusable implementation lives in `src/components/ShowcaseDashboard.tsx`; scenario data lives in `src/lib/showcase-scenarios.ts`.
