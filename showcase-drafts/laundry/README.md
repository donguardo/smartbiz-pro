# Linis Express — Laundry dashboard sample

- Preview route: `/showcase/laundry`
- Theme: Clean aqua and blue
- Starting weekly sales: ₱32,500
- Interactive controls: category sales, profit margin, weekly change, and average customer spend
- Live outputs: sales, profit, customer count, goal progress, daily chart, sales mix, and operational alerts
- Languages: English and Tagalog

This folder is the independent review copy for the laundry scenario. The reusable implementation lives in `src/components/ShowcaseDashboard.tsx`; scenario data lives in `src/lib/showcase-scenarios.ts`.
